# GPT-6 Sol vs GPT-6 Luna: проверка эксперимента

Материалы эксперимента на **30 задачах SWE-bench Verified** из шести проектов:
две модели × два повтора = **120 итоговых наблюдений**. Полный журнал содержит
136 записей, включая 16 инфраструктурных повторных попыток.

| Модель | Решено | Не решено | Нет вердикта, пустой патч | Всего | Доля решённых |
|---|---:|---:|---:|---:|---:|
| GPT-6 Sol | 33 | 24 | 3 | 60 | 55,0% |
| GPT-6 Luna | 23 | 34 | 3 | 60 | 38,3% |

Пустые патчи включены в знаменатель. Smoke и pilot не входят в этот набор.
Точные идентификаторы моделей: `openai/gpt-6-sol`, `openai/gpt-6-luna`.
Условия кампании: общий OpenCode harness 1.18.31, агент `build`, reasoning/variant
`medium`, таймаут 1800 секунд, SWE-bench evaluator 5.0.2, seed `20260920`.

## Быстрая проверка без запуска моделей

Нужен Python 3.11+ для закреплённых зависимостей анализа. Docker, OpenCode,
аккаунт провайдера и ключи для этих команд не нужны.

```sh
git clone https://github.com/H10ms/context-bench-reproducibility.git
cd context-bench-reproducibility
python scripts/verify_release.py
python -m venv .venv
```

Активация окружения: Windows PowerShell — `.venv\Scripts\Activate.ps1`;
Linux/macOS — `source .venv/bin/activate`.

```sh
python -m pip install -r requirements-analysis.txt
python scripts/reproduce.py
```

Установка зависимостей требует интернета; сам пересчёт работает локально.
Команда проверяет SHA-256, manifest, полноту выборки и цепочки `retry_of`,
пересчитывает статистику неизменённым `analysis/statistics.py`, сравнивает
числа с таблицами статьи с учётом округления и создаёт CSV, JSON и семь графиков
в `reproduced/`. Исходные таблицы и рисунки остаются в `article_analysis/`.
Новый скрипт воспроизводит данные графиков, но не обещает их побайтовое совпадение
с исходными иллюстрациями.

## Как читать результаты

На 55 полных парах: обе модели решили 21, только Sol — 11, только Luna — 2,
ни одна — 21. Пять пар исключены из парного анализа исходным правилом `dropna`.
Exact McNemar: двустороннее p = 0,02246; единица анализа — пара повторов.

Исходный task-bootstrap использует **максимум успеха по доступным повторам**,
то есть «хотя бы один решённый запуск», для 29 задач с вердиктами обеих моделей.
Разница Luna − Sol составляет −13,79 п.п., 95% CI [−31,03; 0,00], B=2000.
Это другая величина, чем разница 55,0% − 38,3% по отдельным запускам.
Малая выборка и интервал, включающий ноль, ограничивают обобщение результата.

`actual_cost_usd=0` — наблюдаемое поле событий OpenCode; это не цена API.
`normalized_api_cost_usd=null`: сравнение денежной стоимости недоступно.

**Важно о целостности:** public raw очищен от локальных путей, session ID и
служебных заголовков ошибок. Его SHA отличается от исторического raw.
Все измерения, вердикты, порядок записей и связи retries сохранены.
Freeze и manifest не менялись. Подробности — [RELEASE.md](RELEASE.md).

Публичная копия позволяет независимо пересчитать числа из сохранённых записей.
Она не включает приватные транскрипты, worktree и evaluator logs и потому
не заменяет независимую проверку каждого патча официальным evaluator.
Повторная генерация результатов может отличаться из-за вариативности моделей
и изменений провайдера. См. [REPRODUCIBILITY.md](REPRODUCIBILITY.md).
